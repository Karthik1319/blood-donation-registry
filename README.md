# Blood Donation Registry

Manages blood donors and their donations.

| Folder      | What it is                         | Status          |
| ----------- | ---------------------------------- | --------------- |
| `frontend/` | React (Vite) web app               | Phase 1 done    |
| `backend/`  | Spring Boot REST API               | Not started yet |

**Phase 1 scope:** project structure, reusable UI components, shared page layout (Header +
Footer), Login page and Registration form, with Zod validation.
